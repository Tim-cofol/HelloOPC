# 会议 Agent 需求分析

> Issue: [PER-10 会议Agent](https://linear.app/timzhang/issue/PER-10/会议agent)

## 一、需求概述

将"数字分身"（AI Agent）接入视频会议，使其能以正式参会者身份加入**飞书会议**或**腾讯会议**，代替真实用户完成会中的语音/文字交互。

---

## 二、核心能力拆解

| 能力模块 | 说明 |
|---|---|
| **会议接入** | 以 Bot 身份加入指定会议（链接/会议号） |
| **语音识别 (ASR)** | 实时将会议音频转为文字 |
| **语义理解 & 决策** | 调用 LLM 理解对话上下文、生成回复 |
| **语音合成 (TTS)** | 将文字回复转为自然语音输出 |
| **视频形象（可选）** | 渲染数字人头像，作为视频画面推流 |
| **会议协议处理** | 处理举手、发言、静音等会议室协议 |

## 四、两平台 API 能力对比

| 维度 | 飞书（Lark）会议 | 腾讯会议 |
|---|---|---|
| Bot 加入会议 | ✅ 支持（通过 PSTN / SDK） | ✅ 支持（商业版 REST API） |
| 实时音频流 | ✅ WebRTC/RTC SDK | ✅ TRTC SDK |
| 视频推流（数字人） | ✅ 自定义视频源 | ✅ 自定义视频源 |
| 官方 SDK 成熟度 | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| 开放平台文档 | 完善 | 较完善（需商业版） |
| 国内企业覆盖率 | 高（尤其科技/互联网） | 高（政府/传统行业） |

**建议优先对接飞书**，SDK 生态更完善，开发者文档更友好。
