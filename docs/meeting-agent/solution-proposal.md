## 二、模块详细设计

### 2.1 会议接入层

**飞书方案（推荐）**

- 使用飞书开放平台 `vchat` SDK（RTC）以机器人身份加入会议
- 通过飞书 Bot 事件订阅获取会议邀请（`meeting.invite` 事件）
- 自动入会后拉取音频流，推送自定义音频/视频流

```
飞书 App → 创建机器人 → 订阅会议事件 → vchat SDK 入会 → 获取/发送媒体流
```

**腾讯会议备选方案**

- 使用腾讯会议商业版 REST API 创建/加入会议
- 通过 TRTC SDK 处理实时音视频流

---

### 2.2 音频处理层

| 组件 | 推荐方案 | 备选方案 |
|---|---|---|
| **VAD**（人声检测） | WebRTC VAD / Silero VAD | 固定能量阈值 |
| **ASR**（语音转文字） | 阿里云实时语音识别 / 讯飞 | Azure Speech / Whisper |
| **说话人识别（可选）** | 讯飞说话人分离 | pyannote-audio |

数据流：

```
原始音频帧
    │
    ▼
VAD（过滤静音）
    │
    ▼
ASR 实时流式识别
    │
    ▼
转录文本（带说话人标签）
```

### 2.3 AI 决策层

```python
class MeetingAgentBrain:
    def __init__(self, persona_config: PersonaConfig, llm_client: LLMClient):
        self.persona = persona_config      # 数字分身人格配置
        self.llm = llm_client
        self.context = ConversationContext()  # 会议上下文窗口

    async def on_transcript(self, speaker: str, text: str) -> Optional[str]:
        """收到新的转录文本，决定是否需要发言"""
        self.context.add(speaker, text)

        # 1. 判断是否被点名/提问
        if not self._is_addressed_to_agent(text):
            return None

        # 2. 构建 prompt，调用 LLM
        response = await self.llm.chat(
            system=self.persona.system_prompt,
            messages=self.context.to_messages(),
        )
        return response
```

**上下文管理策略**：
- 滑动窗口：保留最近 N 轮对话
- 会议摘要：超出窗口时自动摘要压缩
- 关键信息：提取议题、决议、Action Items 并置顶

### 2.4 语音合成层

| 方案 | 延迟 | 音色克隆 | 推荐场景 |
|---|---|---|---|
| 微软 Azure TTS | ~300ms | 支持（需样本） | 通用首选 |
| 阿里云 TTS | ~200ms | 支持 | 国内低延迟 |
| ElevenLabs | ~400ms | 支持（高质量） | 高保真克隆 |
| 本地 Coqui TTS | ~800ms | 支持 | 私有化部署 |

---

### 2.5 视频形象层（可选）

若需在会中展示数字人头像：

- **实时驱动**：使用音频驱动口型（如 SadTalker / EMO），将帧推送为自定义视频流
- **静态头像**：使用固定图片作为会中视频（成本最低）
- **虚拟背景**：通过 SDK 自定义视频源接口注入帧数据

## 五、技术栈建议

| 层次 | 推荐技术 |
|---|---|
| 服务框架 | Python + FastAPI / asyncio |
| 会议 SDK | 飞书 vchat SDK（Go/Python 绑定） |
| ASR | 阿里云实时语音 SDK |
| LLM | OpenAI API / 国内模型（通义、混元） |
| TTS | 阿里云 TTS / Azure TTS |

| 部署 | Docker + K8s / 单机部署 |
| 消息队列 | Redis Streams（音频帧异步处理） |

## 六、关键风险 & 缓解措施

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 飞书 vchat SDK 权限审核慢 | 阻塞开发 | 提前申请企业版权限，同步准备腾讯会议方案 |
| LLM 响应延迟高 | 用户体验差 | 流式输出 + 边生成边合成 TTS |
| 多人同时发言干扰 | 识别混乱 | VAD + 说话人分离 |
| 数据隐私合规 | 法律风险 | 会议开始时播报"AI参会提示"，获得知情同意 |
